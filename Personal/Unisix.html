Overview

A simple FPS prototype focused on stencil buffer techniques, custom decal rendering, and a lightweight physically-based shading model.

Core Features

  • Stencil buffer-based scanner effect for revealing hidden objects, including support for transparent materials.
  • Custom PBR implementation within Unity’s built-in render pipeline.
  • Screen-space decal system implemented using post-processing shaders.

Technical Highlights

  • Multi-pass rendering using stencil masking for selective visibility.
  • Custom lighting model based on simplified PBR principles.
  • Decal projection in screen space without modifying underlying geometry.
