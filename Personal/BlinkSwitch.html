Overview

A simple FPS prototype featuring split-screen gameplay and multiple real-time post-processing effects. The project focuses on experimenting with screen-space rendering techniques and visual stylization.

Core Features

  • Multiple post-processing modes with runtime switching.
  • Cartoon-style rendering using outline detection combined with dithering.
  • Sketch effect based on Difference of Gaussians (DoG) and edge detection.
  • Old TV screen effect using UV distortion and sinusoidal noise functions.
  • Split-screen support using Unity's Input System with full gamepad integration.
  • Custom lightweight G-Buffer implementation to improve outline stability on close geometry.
  • Basic Temporal Anti-Aliasing (TAA) implementation to reduce visual artifacts.
